# Governance — Open Order

This repository is maintained through the KNIT-NZ GitHub account as part of KNIT's independent, non-partisan public-interest civic infrastructure work. See [knit.nz](https://www.knit.nz/) for the wider project.

## Maintainer responsibilities

The current repository maintainer controls merge and release decisions, reviews contributions, protects source and methodological integrity, and manages repository access. The CODEOWNERS file identifies the account responsible for review routing; it does not establish that independent review is currently mandatory. Changes affecting rights, security, data handling or public claims should receive appropriate scrutiny before publication.

## Institutional stewardship

KNIT's charitable governance arrangements are distinct from repository permissions. This document does not replace the trust deed or confer trustee or executive authority. Ownership, delegations, material funding and asset stewardship must be documented through the applicable institutional arrangements. As the organisation develops, repository access, oversight and succession should be reviewed and updated. No funder, party or external stakeholder acquires control over research conclusions or technical outputs simply by providing support.

## Openness and accountability

Original software is released under Apache 2.0 within the documented [licensing scope](LICENSE-SCOPE.md). Separate rights, cultural guardianship, privacy and security obligations remain applicable. Decisions about material changes should be traceable through issues, pull requests, commits or appropriate governance records. The project may be independently reused under applicable licences; such reuse does not imply endorsement by KNIT or any public institution.

Report ordinary issues publicly and sensitive issues through the process in [SECURITY.md](SECURITY.md). Contribution guidance is in [CONTRIBUTING.md](CONTRIBUTING.md).
